# 🍽️ FoodCart — Smart Food Ordering Web Application

Live Demo: https://v0-zomato-e-commerce-site.vercel.app

---

## 📖 About the Project

**FoodCart** is a modern, responsive food ordering web application built using **Next.js, TypeScript, JavaScript, and Tailwind CSS**.  
It helps users browse dishes, select their favorite food items, and find restaurants that serve those dishes.

Instead of searching manually, users can simply select the dish they want and the application will display the relevant restaurants, making the ordering process faster and more convenient.

### 🎯 Objectives

- ✔️ Simplify the food ordering process  
- ✔️ Find restaurants based on selected dishes  
- ✔️ Provide a fast and smooth user experience  
- ✔️ Build a clean, modern, responsive UI  

---

## 🚀 Features

- 🍕 Browse different food items and dishes  
- 🏪 Find restaurants based on selected dishes  
- 🛒 Add food items to cart  
- 🧾 View cart and order summary  
- 📱 Fully responsive UI  
- ⚡ Fast and interactive interface
